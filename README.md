# MeterBox for REAPER 8

A first public test build of a compact stereo peak meter that reads the REAPER master track directly.

## Install with ReaPack

1. Open **Extensions > ReaPack > Import repositories**.
2. Add this exact URL:

   https://raw.githubusercontent.com/thevardas21ofc-cloud/MeterBox-ReaPack/main/index.xml

3. Synchronize packages, browse packages, search **MeterBox**, and install.
4. In the Actions list, run **MeterBox - REAPER Master Meter**.

Run **MeterBox - Open Settings** to change appearance. You can also right-click the meter.

## Included in this test build

- Direct stereo peak readings from the REAPER master track.
- Continuous L/R bars and peak-hold markers.
- Floating meter window.
- Separate settings window with persistent labels, peak-marker, size and palette controls.

**The transport-bar overlay is not included in this test build.** This is a working baseline for testing the master feed, display and settings before the transport overlay is added back in a later release.

Report any error with its exact text and line number, plus your REAPER version and operating system.
